# StowKit 1.3.0

Filing rules, and StowKit now updates itself.

## Before you install: what is not proven

- **The updater has installed an update once**: a signed 1.2.9 test build updated itself to this
  release from a user-writable folder. Installing into /Applications and silent automatic installs
  are untested.
- **Filing rules are kept on each Mac** and don't sync yet. They haven't been used on a real archive
  beyond testing.
- **Tested on one Mac only**, the owner's (Apple Silicon, macOS 27). Household sharing is still
  experimental and untested with two iCloud accounts.
- If you chose an inbox folder in a 1.2.0 test build, choose it again: a test bug in development
  cleared the setting. Released 1.2.0 users are not affected.

## What's new

- **Filing rules** (Settings → Rules). For example: “any text contains the words *novocare* → add to
  Medical, tag *insurance*, mark reviewed”. Match any of the words, all of them, a phrase, or a
  regular expression, in the title, sender, file name, or document text, ignoring case and accents.
  Rules run once a document's text is read, after Apple Intelligence, and win over its suggestions,
  but never change a field you edited yourself. **Apply to Existing Documents** runs them over your
  archive, and a document's details say which rule filed it.
- **Automatic updates.** StowKit checks its GitHub releases daily, and on demand with **Check for
  Updates…** in the StowKit menu. Updates are signed, notarized, and verified before they install.
  Settings → Updates can also download and install them without asking.
- **Ready for synced rules.** 1.3.0 keeps kinds of iCloud records it doesn't recognise for later,
  instead of stopping sync, so a future version can sync rules without stranding this one.

## Good to know

- StowKit now includes one outside component, Sparkle, the standard macOS updater.
- 1.2.0 and earlier don't update themselves: install 1.3.0 by hand once. From then on it updates
  itself.

## Installation

Open `StowKit-1.3.0.dmg` and drag StowKit to Applications, replacing the old version. Requires
macOS 14 or later. Signed with Developer ID and notarized by Apple; use the SHA-256 sidecar to
verify the download.
