# StowKit 1.2.0

One archive, kept in iCloud. Add documents from your iPhone through an inbox folder. And a new
icon.

## Before you install: what is not proven

- **Tested on one Mac only**, the owner's (Apple Silicon, macOS 27). Nothing in this release has run
  across two Macs, so joining the archive from a second Mac, and two Macs sharing the work of
  reading documents from the inbox folder, are untested.
- **Household sharing is still experimental** and untested with two iCloud accounts.
- **Permanent deletion and Remove Download** are still tested only against a simulated iCloud.
- A Mac with documents of its own, whose iCloud already holds a different archive, stays separate and
  says so. Combining archives isn't built.

## What's new

- **One archive.** StowKit keeps your archive in iCloud, with copies on this Mac. The archive picker
  is gone; the button at the bottom of the sidebar shows sync status. On launch StowKit reconnects to
  your archive, or creates it (asking first if this Mac already has documents). **Pause iCloud** in
  Settings is remembered.
- **iCloud turns itself back on.** If an earlier version turned iCloud off for your archive (1.0.0's
  archive switch did, and so could an iCloud account notice), 1.2.0 reconnects it. A duplicate copy of
  your own archive that 1.1.0 could open is removed, but only if it holds nothing your archive lacks.
- **Inbox folder.** In Settings → Inbox Folder, choose a folder in iCloud Drive. Scan or save a PDF or
  image into it from the Files app on your iPhone, and StowKit imports it, reads it, suggests
  details, and moves the file to the Trash. A file that can't be imported is left in the folder.
- **Suggestions for documents from iCloud.** A document that arrived from iCloud without suggestions
  now gets them on this Mac, after giving the Mac that added it ten minutes to go first.
- **The document list no longer overlaps** when a document's title changes after it's read.
- **A new app icon.**

## Good to know

- Nothing about how your documents are stored changes on upgrade, and the sync format is unchanged,
  so a Mac still on 1.1.0 keeps syncing.
- StowKit can now write to folders you choose, which it needs to remove files it took from the inbox
  folder.

## Installation

Open `StowKit-1.2.0.dmg` and drag StowKit to Applications, replacing the old version. Requires
macOS 14 or later. Signed with Developer ID and notarized by Apple; use the SHA-256 sidecar to
verify the download.
