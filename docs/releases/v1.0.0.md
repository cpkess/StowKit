# StowKit 1.0.0

StowKit is a native Mac archive for household paperwork: drop documents in, and StowKit reads
them, suggests how to file them, and makes them searchable — all on your Mac.

## Before you install: what is not proven

- **Household sharing is experimental.** Sharing an archive with a different iCloud account has
  never been tested with two accounts. Treat it as a preview; don't rely on it for documents
  you can't afford to lose track of.
- **Remove Download** (freeing disk space by keeping an original only in iCloud) has been tested
  against a simulated iCloud, not yet against a real one.
- iCloud sync between your own Macs passed live tests on one Mac with one account; a second
  physical Mac has not been tested.
- Tested on Apple Silicon running macOS 27. The Intel build and macOS 14–26 compile, but have
  not been run.

## What's new since the alpha

- **Fixed a freeze on launch.** A layout bug rebuilt the document preview about 20 times a
  second; with Apple's PDF viewer this piled up until the app stopped responding. The preview
  now draws pages itself and stays at idle CPU.
- **Apple Intelligence now reads medical records.** Apple's default safety filter refused
  ordinary medical forms, so they silently got weaker suggestions. StowKit now asks again in a
  way Apple permits for your own documents, and still checks every answer against the text.
- **Readable titles and real dates.** Filenames like
  `Patient_FORM_2026-09-17T00_18_36Z.pdf` become "Patient FORM", dated September 17, 2026.
  Existing documents are cleaned up once, unless you've edited them.
- **A clearer details pane.** Title, date, sender, collections, tags, and summary come first;
  processing and file details sit under **More Details**. One "Needs review" banner, a labelled
  **Add to Collection** button, and plain wording throughout.
- **Disk use in Settings**, broken down by originals, database, search, thumbnails, and any
  leftover iCloud test data.
- **Keep Downloaded** and **Remove Download** for documents already safe in iCloud.
- A note explains that the first scanned page can take up to a minute while Apple's text
  recognition starts up.

## Good to know

- You can no longer select text inside the preview pane; use **View Text** or **Open a Copy**.
- Trash is kept indefinitely and still uses disk space; there is no permanent delete yet.
- Your originals are never modified, and reading and suggestions never leave your Mac.

## Installation

Open `StowKit-1.0.0.dmg` and drag StowKit to Applications. Requires macOS 14 or later.
Signed with Developer ID and notarized by Apple. Use the SHA-256 sidecar to verify the download.
Your existing archive opens as-is; back it up first if it matters to you.
