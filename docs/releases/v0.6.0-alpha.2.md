# StowKit v0.6.0-alpha.2 — signed macOS distribution

This release packages StowKit with Gamergrams Developer ID signing, hardened runtime, and Production CloudKit configuration. The app and DMG are notarized by Apple with stapled tickets. The provisioning profile allows all Macs; individual device registration is not required.

## Installation

Download `StowKit-0.6.0-alpha.2.dmg`, open it, and drag StowKit to Applications. The app includes Apple Silicon and Intel binaries and requires macOS 14 or later. Distribution verification was performed on Apple Silicon running macOS 27; a second physical Mac has not yet been tested.

This is version 0.6.0, build 3. The normal app excludes the live verification runner. iCloud remains off until enabled in Settings; enabling it uploads the active archive, including Trash and extracted text. Back up the complete local archive before testing. Development and Production CloudKit archives are separate: an existing Development binding reports a configuration mismatch rather than silently switching environments.

## Verification and limitations

- Strict code-signature verification, Apple notarization, ticket stapling, and Gatekeeper assessment passed for the app and final DMG. The mounted DMG's app was checked again.
- The Production schema is deployed. An isolated same-account smoke test passed multi-chunk original upload, independent hash verification, searchable text catch-up without materializing the original, byte-identical explicit download, and edits converging between two local stores. An initial asset-download failure passed on retry; only fictional generated data was used.
- The latest full regression suite ran 95 tests with all cloud tests passing, but two OCR tests failed in macOS 27's Vision runtime. A targeted rerun left one image/scanned-PDF OCR test failing. OCR recovery remains unverified; no speculative workaround is included.
- Household invitations, a second physical Mac, cross-account permissions and revocation, quota failures, and interrupted live transfers remain unverified. Sharing is experimental.
- Cloud thumbnails, automatic original-file eviction, pin controls, and push-driven background synchronization remain unfinished.

Use the SHA-256 sidecar to verify the downloaded DMG. Signing and notarization establish distribution checks, not completion of the outstanding iCloud household acceptance tests.
