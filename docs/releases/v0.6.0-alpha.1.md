# StowKit v0.6.0-alpha.1 — iCloud development preview

This preview adds opt-in CloudKit synchronization to the native macOS document archive: immutable original transfers, searchable extracted text, metadata edits, conflict review, account isolation, and household-sharing UI.

## Download and installation

Download `StowKit-0.6.0-alpha.1.dmg`, open it, and drag StowKit to Applications. The app contains both Apple Silicon and Intel binaries and targets macOS 14 or later; this release was verified on Apple Silicon with macOS 27 and Xcode 27.

**This asset is a development-signed preview, not a notarized public-distribution build.** Its embedded Gamergrams development profile currently includes one provisioned Mac and expires September 19, 2027. It uses the CloudKit Development environment; its data does not constitute a Production iCloud backup. Do not bypass macOS security warnings if your Mac cannot run it. A generally installable, notarized release remains future work.

The DMG includes the normal app; the explicit live-test runner is disabled. iCloud is off until enabled in Settings. Enabling it uploads the active archive, including Trash and extracted text. Back up the complete local archive before testing. No automatic original-file eviction or permanent deletion is enabled.

## Verification and known limitations

- Signed Release build and strict signature verification pass.
- Live private CloudKit smoke test passed multi-chunk original upload and independent verification, searchable text catch-up without local original materialization, byte-identical explicit download, and bidirectional edits between two isolated local stores. Only generated fictional bytes were uploaded.
- All cloud integration tests passed. The latest full regression run executed 95 tests but was not fully green: two OCR tests failed with six assertions/errors in macOS 27's Vision runtime. A targeted rerun left one image/scanned-PDF test failing due to a missing generated E5 model resource. No speculative OCR workaround is included.
- Household invitations, a second physical Mac, cross-account permissions/revocation, quota failures, and interrupted live transfers remain unverified. Sharing is experimental.
- Cloud thumbnails, storage eviction/pin controls, push-driven background synchronization, and Production schema deployment are not included.

The SHA-256 sidecar allows verification of the downloaded DMG. Source and setup instructions are included in the repository; build with your own development provisioning if your Mac is not in the embedded profile.
